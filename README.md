# Chris Nightingale

**Freelance Senior .NET Developer**

I help businesses understand, maintain and modernise the software they already depend on. My focus is existing .NET applications: keeping them useful, resolving difficult problems and making them easier to change.

I’m comfortable getting to grips with unfamiliar, complicated systems, including those where the documentation hasn’t kept up. I work across application code, databases, integrations and infrastructure to understand how the pieces fit together.

## What I work on

- **Application maintenance & development** — Fix recurring problems, extend business functionality and make everyday changes easier to deliver.
- **Legacy .NET modernisation** — Untangle dependencies, improve maintainability and move towards modern .NET in manageable steps.
- **Azure migration** — Understand application and infrastructure dependencies, plan a practical migration and adapt the software for its new environment.
- **Production troubleshooting** — Investigate failures and performance issues, trace underlying causes and improve diagnostics and observability.

I start with how the software is used, what the business needs and where changes carry risk. I favour incremental, testable improvements that preserve what works and leave the system easier for the next engineer to understand.

## Technology

**Core:** C# · .NET · ASP.NET Core · ASP.NET MVC · SQL Server · Azure  
**Also:** REST APIs · React · Docker

I work with both legacy and modern stacks, choosing changes around the needs of the application.
